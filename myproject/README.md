# MyProject - Django Web Application

## 📌 Project Overview

MyProject is a web application developed using Python and Django.
The project provides user authentication, profile management and
other web application features with a user-friendly interface.

## 🚀 Features

- User Registration
- User Login
- User Logout
- User Profile
- Edit Profile
- Change Password
- Authentication
- Database Integration
- Responsive Web Interface

## 🛠️ Technologies Used

- Python
- Django
- HTML5
- CSS3
- JavaScript
- SQLite
- Bootstrap
