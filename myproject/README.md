# MyProject - Django Web Application

## 📌 Project Overview

MyProject is a web application developed using Python and Django.

The project provides user authentication, profile management,
and other web application features with a user-friendly interface.

## 🚀 Features

- User Registration
- User Login
- User Logout
- User Profile
- Edit Profile
- Change Password
- Authentication
- Database Integration
- Responsive Web Interface

## 🛠️ Technologies Used

- Python
- Django
- HTML5
- CSS3
- JavaScript
- SQLite
- Bootstrap

⚙️ Installation & Setup
1. Clone the Repository


git clone https://github.com/gauravpatil8799/myproject.git


2. Go to the Project Folder


cd myproject

3. Create Virtual Environment

python -m venv venv

4. Activate Virtual Environment

Windows:

venv\Scripts\activate

5. Install Required Packages

pip install -r requirements.txt

6. Run Database Migrations

python manage.py migrate

7. Start the Development Server

python manage.py runserver

🌐 Open in Browser

After starting the development server, open:

http://127.0.0.1:8000/

🗄️ Database

This project uses SQLite as the default database.

Database file:

db.sqlite3
